# Design review: wizard, Sheet and Play (2026-10-29)

Checked the running app against `hero-wizard/spec.md` and `hero-sheet/spec.md`. Theme tokens, local fonts, the draft lifecycle, the wizard shell, the edit summary with revert, the Sheet page and the ability availability rules all match the specs. The items below don't yet. Play may still be in progress; those items are listed so nothing gets missed.

## Roll flow (hero-sheet spec, Roll flow)

- [ ] No step bar ("Dice and mods, Results, Resolve").
- [ ] Power and Quality selects have no "Take a d4" option. A fixed trait shows just its name, without "set by the ability".
- [ ] Results are a text list ("Max: 12 (Speed d12)"). The spec has three dice cards (label, value, die icon, source) and one effect card per effect with the total in large type. The text list also writes dice as "d12", which breaks the icon rule.
- [ ] The default mod went onto the Hinder effect. The spec puts every checked mod on the **first** effect to start.
- [ ] Mods can only be moved by dragging. Each chip also needs its own menu ("Move to Hinder"), for keyboard and phone use.
- [ ] No Back button on the Results step.
- [ ] Done shows no toast and has no Undo. The spec has "Roll recorded. Used up: …" with Undo for about ten seconds.
- [ ] The dialog is 640 px wide; the spec says 560 px. Minor.

## Play mode

- [ ] **Modes** use a select. The spec has radio rows with zone chips, "Normally needs Yellow" on modes above the effective zone, the current mode's dice changes and restriction under the list, and the stay-in-mode notice when the zone improves. Switching freely does work, which is right.
- [ ] The **Dice** card drops traits a mode removes, which is right, but doesn't mark changed dice.
- [ ] **Divided** has the Civilian/Heroic toggle, but not the transition reminder line, the personality and status dice swap, or the "Not in this form" list.
- [ ] **Your minions** panel is missing for the Minion Maker test hero (rows with die, form, action, mods, Use, shrink and remove; Use with its own mods; fixed action or any action for Autonomous).
- [ ] **History** shows absolute dates on older entries ("Oct 28, 2026, 1:50 AM"); the spec asks for relative times. The latest roll isn't set apart as a card with the accent border.
- [ ] **Phone (under 760 px):** no sticky top bar and no Actions, Status and History tabs yet. The page stacks without horizontal scroll, which is good.

## Wizard (hero-wizard spec)

- [ ] **Form split** (Divided) uses a select per trait labeled "Fitness (d10)". The spec and mockup have a table with die icons and a Both/Civilian/Heroic segmented control, with live tallies ("Both forms, powers: 2 of 2"). The labels also write dice as text where an icon can go.
- [ ] The Background roll button reads "Roll d10 and d10"; use die icons.
- [ ] Dice in assign slots and "Dice out" render at 16 px. The spec says 24 px in dice rows, assign slots and tables; 16 px only inline in sentences.
- [ ] The "Dice out" hand-off box has a solid border. The spec has a dashed one. Minor.
- [ ] Principles listed in the edit summary have no Overcome icon before the name; every listed ability shows its action icons.
- [ ] After "Revert changes" is confirmed, focus doesn't go back to the Revert button.
- [ ] The In progress group appears inside the Your heroes section, under its buttons. The spec puts it above Your heroes. Minor.
